# Luna Mechanical Delegation

Use after the user or coordinating Astra/Sol selects Luna, not automatic matching of every mechanical task. Preserve the existing owner and callback recipient. Direct Sol keeps its actual settings and owns its task, never starts Astra; Astra-led Sol remains its owner's implementer. Direct Luna stays local.

Use [luna-worker.md](../architect-implementer/references/luna-worker.md) for the shared role, execution and acceptance boundaries, not a second copy of them here.

Apply [shared boundaries](../architect-implementer/references/boundaries.md) within host authorization; no personal global AGENTS file is required. Save the mechanical assignment, excluded decisions and callback identity/settings before dispatch. Follow [checkpoint ownership](../architect-implementer/references/checkpoint.md); this entry does not transfer another role's records to its caller. Later messages carry deltas/current pointers.

Load runtime support for the actual operation. Do not reload unchanged support/history within a continuous turn.
